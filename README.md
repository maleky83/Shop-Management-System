# Shop-System

A shop management system 
Product, category, cart , order

Features:
* Web Api
* Clean Architecure 
* RESTful
* Entity Framework Core with Fluent API
* CQRS , Mediatr
* Serilog
* User JWT and ASP.NET Core Identity
* Dependency Injection
* Auto Mapper
* FluentValidation
* Swagger And Postman API documentation
* Seed Data
